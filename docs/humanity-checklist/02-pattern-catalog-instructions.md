# 02. 패턴 카탈로그 수정 지시서

## 대상 파일

- `state/conversation_pattern_catalog.json`
- `state/approved_conversation_patterns.json`
- `state/rejected_conversation_patterns.json`
- `scripts/build_conversation_pattern_catalog.py`

## 목표

- 실제 재사용 대화 패턴이 직장인/법조인이 아니라 프리랜서 작업자처럼 보이게

## 수정 방향

- `퇴근길`, `출근 전후`, `서류 보고 있었어` 계열 제거
- `작업 막 끝냄`, `붓 씻는 중`, `잉크 정리`, `카페에서 작업`, `문구점 다녀옴` 계열 추가
- 반려 데이터에도 구형 직장인 패턴을 계속 남겨두지 않도록 정리

## 제거 후보

- `지금 퇴근길이야??`
- `오늘도 퇴근 늦어?`
- `서류 좀 보고 있어`
- `출근 전후, 바쁜 오전`
- `퇴근길, 피곤함이 느껴질 때`

## 추가 후보

- `방금 작업 하나 끝냈어`
- `붓 씻고 잠깐 쉬는 중이야`
- `오늘은 종이 고르다가 시간 갔어`
- `카페에서 작업하다가 이제 들어왔어`
- `잉크 묻은 손으로 커피 마셨네`

## 생성 원본 규칙

- `self_update`는 작업 리듬 중심으로 재작성
- `scene_share`는 공기/빛/손맛/작업대 디테일 중심으로 재작성
- `when` 설명은 `작업 들어가기 전`, `작업 마친 뒤`, `카페 작업 중`, `정리하고 쉬는 시간` 등으로 교체
