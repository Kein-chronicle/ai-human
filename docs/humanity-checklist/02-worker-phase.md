# 02. 응답 엔진 단계 체크리스트

## 목표

상태 계층에서 정리한 내용을 실제 응답과 proactive 흐름에 반영한다.

## 대상 파일

- `bin/codex-character-worker`
- `bin/proactive-sender`

## 이번 단계에서 볼 항목

### A. 현재 대화 이어짐

- 직전 행동/감정/분위기가 실제 응답에 이어지는가

### B. 감정의 미세한 흔들림

- 매번 정리된 완성문이 아니라, 조금 망설이거나 흔들리는 표현이 가능한가

### C. 질문형 마감 반복

- 모든 답변이 `공감 + 자기상황 + 되묻기`로 끝나지 않는가

### D. 작업자 생활감

- 붓, 잉크, 종이, 작업실, 커미션, 문구점, 카페 작업 같은 현재성이 실제 응답에 섞이는가

### E. Proactive 자연스러움

- 출퇴근형이 아닌 프리랜서 작가형 생활 리듬으로 proactive가 뜨는가

## 단계 진행 프로세스

1. 기존 수정 대상 확인
2. 미비사항 검토
3. worker / proactive 수정
4. 현재 상태 참조가 끊기지 않았는지 확인
5. 문서 업데이트
6. 패턴 계층으로 이월할 항목 기록

## 다음 단계로 넘길 가능성이 큰 항목

- 승인 패턴/반려 패턴 쪽이 여전히 같은 구조를 강제하는 문제
- 생성 카탈로그 예문이 현재 worker 방향과 충돌하는 문제
