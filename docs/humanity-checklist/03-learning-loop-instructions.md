# 03. 학습 루프 수정 지시서

## 대상 파일

- `tools/conversation_learning_loop.py`

## 목표

- 학습 루프가 옛 직업 어휘를 계속 강화하지 않게
- 캘리그라피 작가의 현재 어휘를 중심으로 기억과 패턴이 쌓이게

## 수정 방향

- 법조/직장인 키워드 제거 또는 가중치 축소
- 캘리그라피/작업실/문구/커미션/인스타 키워드 추가

## 축소 또는 제거 후보

- `법원`
- `의뢰인`
- `계약`
- `재판`
- `변론`
- `로펌`
- `사무실`
- `퇴근`

## 추가 후보

- `붓`
- `잉크`
- `종이`
- `작업실`
- `커미션`
- `연습`
- `문구점`
- `포트폴리오`
- `인스타`
- `글씨`

## 목표 효과

- 오래 대화할수록 응우가 `전직 변호사`가 아니라 `현재 글씨를 쓰는 사람`으로 더 강하게 축적되게 만들기
