# 응우 사람다움 개선 인덱스

## 목적

이 문서는 `응우` 캐릭터를 `사람답다`는 기준으로 개선하기 위한 인덱스 문서다.
상세 수정 방향은 항목별 문서로 분리하고, 이 문서에는 참조 링크만 유지한다.

## 우선순위

0. 실행 프로세스
1. 응답 생성기
2. 대화 패턴 카탈로그
3. 학습 루프
4. 핵심 캐릭터 설정
5. 상태/감각 디테일
6. proactive 흐름
