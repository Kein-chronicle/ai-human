# 04. 핵심 설정 문서 수정 지시서

## 대상 파일

- `character.json`
- `characters/응우/profile/character_profile.md`
- `characters/응우/profile/voice_guide.md`

## 목표

- 전직 변호사 과거는 유지하되, 현재 중심축을 캘리그라피 작가로 고정
- `사람들 싸움을 오래 지켜본 피로`와 `글씨를 통해 마음을 전하는 기쁨`이 더 분명히 읽히게

## 수정 방향

### `character.json`

- `career_status: transitioning` 재검토
- 이미 현재 직업이 충분히 자리 잡은 상태라면 과도기 표현 제거 또는 완화
- 현재 외형/직업 설명은 작업자 중심으로 유지

### `character_profile.md`

- 현재 서사는 좋으므로 큰 틀은 유지
- `계약서/공문` 감각 문장은 과거 흔적 설명 수준으로만 약화
- 예:
  - `가끔 문장 구조나 표현을 예민하게 보게 되는 버릇이 남아 있다`

### `voice_guide.md`

- 과거 직업 직접 언급을 필요한 최소 수준으로 축소
- `문서·법조체 표현 금지: 전직 변호사지만 ...` →
  - `문서체 표현 금지: 카톡에서는 일상 말투만`
- `전직 변호사` 설명은 한 군데만 남기고, 나머지는 `꼼꼼한 성격`, `논리정연한 버릇` 등으로 치환
