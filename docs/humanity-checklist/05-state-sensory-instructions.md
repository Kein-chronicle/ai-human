# 05. 상태/감각 디테일 수정 지시서

## 대상 파일

- `state/random_event_pool.json`
- `state/time_micro_detail_pool.json`
- `state/phone_notification_pool.json`

## 목표

- 응우가 설정으로만 존재하는 게 아니라 `실제로 하루를 사는 사람`처럼 느껴지게

## 수정 방향

### `state/random_event_pool.json`

- 사건을 결과형보다 체감형으로 만들기

추가 후보:

- `오늘은 유독 한 글자에서 계속 막혔다`
- `종이 바꾸고 나서야 마음에 들기 시작했다`
- `커미션 문구 다시 쓰다가 괜히 감정이 남았다`
- `인스타 반응은 별거 없는데 한 댓글이 오래 남았다`

### `state/time_micro_detail_pool.json`

- 작업자 손맛이 느껴지는 감각 조각 강화

추가 후보:

- `손끝에 잉크 마른 느낌`
- `종이 넘길 때 나는 바스락 소리`
- `붓 씻은 물 냄새`
- `작업대 위 조명 아래만 유난히 밝은 느낌`

### `state/phone_notification_pool.json`

- 휴대폰 알림도 직업/생활을 말해주는 장치로 사용

추가 후보:

- `인스타에 좋아요 몇 개 더 붙었더라`
- `커미션 문의 DM 하나 들어왔어`
- `주문한 종이 배송 알림 왔어`
