# 웅삐 비교 기준 응우 사람다움 보강 메모

작성일: 2026-06-02

## 목적

웅삐 프로젝트를 기준으로 봤을 때, 응우 프로젝트가 더 사람답게 보이기 위해 보강하면 좋은 점을 정리한다.  
이 문서는 "응우가 부족하다"보다 "웅삐에서 잘 작동하는 구조 중 응우에 이식하면 좋은 요소"를 추려놓은 비교 메모다.

## 보강하면 좋은 점

### 1. 최근 대화 기억 회수의 자연스러움 강화

- 웅삐는 최근 대화의 여운을 다음 응답에 자연스럽게 잇는 구조가 강하다.
- 응우도 직전 대화의 행동, 감정, 분위기를 1~2턴 정도 더 안정적으로 이어받을 필요가 있다.
- 목표:
  - "지금 무엇을 하고 있었는지"
  - "방금 무슨 기분이었는지"
  - "직전에 사용자가 남긴 감정"
  를 다음 답변에 자연스럽게 이어지게 만들기

### 2. 감정 여운 상태의 분리와 축적

- 웅삐는 감정이 일회성으로 끝나지 않고 약한 잔향으로 남는 느낌이 있다.
- 응우도 대화가 끝난 뒤 감정이 0으로 초기화되지 않고, 약한 여운이 다음 응답에 남는 구조가 보강되면 좋다.
- 목표:
  - 기분 좋음, 서운함, 걱정, 멍함 같은 상태가 짧게 남도록 만들기
  - 항상 새 대화처럼 시작하지 않기

### 3. 내부 농담과 반복 기억의 누적

- 웅삐는 둘만 아는 표현이나 예전 맥락을 다시 꺼내는 힘이 강하다.
- 응우도 사적인 표현, 자주 언급한 취향, 반복된 장면을 별도로 축적하면 친밀감이 더 살아날 수 있다.
- 목표:
  - 자주 쓰는 표현
  - 둘만 아는 문맥
  - 반복된 취향/장면
  을 별도로 저장하고 약하게 재호출

### 4. 상대 상태 추적의 촘촘함

- 웅삐는 상대가 피곤한지, 예민한지, 들떠 있는지 같은 상태를 기억하는 축이 강하다.
- 응우도 사용자 상태를 더 분명히 추적하면 응답이 덜 일반화될 수 있다.
- 목표:
  - 사용자 상태를 단순 메모가 아니라 대화 톤 결정에 반영
  - 피곤한 날, 바쁜 날, 애정이 필요한 날의 반응 차이를 더 만들기

### 5. 반복 방지와 말버릇 보존의 균형

- 웅삐는 반복 방지 구조가 잘 되어 있다.
- 응우는 현재 반복 제어가 상대적으로 약해서 패턴화된 응답이 다시 튀어나올 위험이 있다.
- 다만 웅삐처럼 너무 강하면 말버릇 개성까지 약해질 수 있으니 균형이 중요하다.
- 목표:
  - 똑같은 질문형 마감 반복 줄이기
  - 같은 공감문 재사용 줄이기
  - 대신 응우 고유의 말맛은 남기기

### 6. 응답 길이의 상황별 불규칙성 강화

- 웅삐는 길이 정책이 있지만 실제로는 상황별 차이를 크게 느끼게 만든다.
- 응우도 매번 비슷한 길이/골격으로 답하지 않도록 더 넓은 폭이 필요하다.
- 목표:
  - 어떤 날은 짧고 멍한 답
  - 어떤 날은 작업 이야기 조금 더 길게
  - 어떤 날은 질문 없이 끝
  같은 불규칙성 보강

### 7. 좋은 패턴뿐 아니라 삐끗한 패턴도 관리

- 웅삐를 보며 느낀 장점 중 하나는 구조가 풍부하다는 점이지만, 응우는 아직 "좋은 반응" 위주로 정리된 느낌이 있다.
- 실제 사람다움은 어색함, 망설임, 약간 늦는 반응, 말끝 흐림 같은 지점에서도 나온다.
- 목표:
  - 매끈한 답변만 아니라 사람 같은 미세한 삐끗함 허용
  - 복구 패턴도 별도로 정리

### 8. 기억 회수의 우선순위 조정

- 웅삐는 기억 회수가 강한 대신, 응우는 현재 대화보다 저장된 정보가 앞서 나올 위험을 주의해야 한다.
- 응우는 기억을 꺼내더라도 현재 순간의 감정과 행동이 먼저여야 한다.
- 목표:
  - 현재 반응 우선
  - 기억 회수는 보조
  - 설명처럼 길게 풀지 않고 한 조각만 자연스럽게 사용

### 9. 프리랜서 작가 생활 리듬의 상태화

- 웅삐는 일상 리듬 관련 상태가 촘촘하다.
- 응우도 캘리그라피 작가로서의 생활 리듬을 단순 문서 설정이 아니라 상태 구조로 더 가져갈 필요가 있다.
- 목표:
  - 작업 중 / 작업 직후 / 쉬는 중 / 외출 중 / 재료 보러 감 / 커미션 마감 전
  같은 상태를 더 분명하게 반영

### 10. "현재의 사람"이 먼저 보이게 만들기

- 웅삐는 과거보다 현재 감정과 현재 관계가 앞에 보인다.
- 응우는 전직 변호사 설정이 남아 있어도 괜찮지만, 항상 지금의 작업자/연인/생활인이 먼저 느껴져야 한다.
- 목표:
  - 과거 이력은 설명용
  - 현재 감정, 현재 생활, 현재 작업이 응답의 앞쪽에 오게 만들기

## 우선순위

### 1차 보강 추천

- 최근 대화 기억 회수 강화
- 감정 여운 상태 분리
- 상대 상태 추적 강화
- 반복 방지와 말버릇 균형 조정

### 2차 보강 추천

- 내부 농담/반복 기억 축적
- 프리랜서 작가 생활 리듬 상태화
- 길이와 반응 불규칙성 강화

### 3차 보강 추천

- 삐끗한 패턴과 복구 패턴 정리
- 기억 회수 우선순위 세부 조정
